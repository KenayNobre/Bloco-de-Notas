# 📓 Bloco de Notas

Um projeto desenvolvido para treinar conhecimentos em **JavaScript** e o uso do **localStorage** para armazenamento de informações no navegador. Este bloco de notas permite criar, visualizar, e excluir anotações de forma prática e simples.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Para a estruturação da página.
- **CSS3**: Para estilização e design do aplicativo.
- **JavaScript**: Para a lógica do aplicativo, manipulação do DOM e integração com o `localStorage`.

---

## ⚙️ Funcionalidades

- **Adicionar Anotação**: Crie uma nova anotação com título e corpo. A anotação é salva automaticamente no `localStorage`.
- **Carregar Anotações**: Todas as anotações salvas no `localStorage` são carregadas automaticamente ao iniciar a aplicação.
- **Deletar Anotação**: Remova anotações específicas tanto do `localStorage` quanto da interface do usuário.
- **Exibir Anotação**: Visualize os detalhes (título e corpo) de uma anotação selecionada.
